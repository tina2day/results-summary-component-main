# Results Summary Component

This is my solution to the [Results Summary Component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/results-summary-component-CE_K6s0maV).

The project started as a responsive HTML and CSS challenge and was later extended with JavaScript to make the component interactive.

## Overview

### Features

- Responsive layout for desktop and mobile devices
- Dynamic rendering of results using JavaScript
- Loading data from a JSON file using the Fetch API
- Adding and deleting results
- Form validation
- Automatic calculation of the average score
- Filtering results based on the average score
- Loading and error states with retry functionality
- Modal dialog for adding new results

## What I Learned

While working on this project, I improved my HTML, CSS, and JavaScript skills.

**JavaScript modules**

I learned how to split JavaScript code into separate modules to make it more organized, reusable, and easier to maintain.

**Asynchronous JavaScript**

I practiced working with Promises, `async/await`, and the Fetch API to load data from a JSON file. I also implemented loading states, error handling, and retry functionality.

**DOM manipulation**

I learned how to dynamically create, render, update, and remove elements based on user interactions.

**Array methods**

I practiced using `map()`, `filter()`, `find()`, and `reduce()` to process data, calculate statistics, and filter results.

**Form validation**

I gained experience validating user input and handling form submissions.

**State management**

I learned how to manage application data and keep the interface synchronized when results are added, deleted, or filtered.
